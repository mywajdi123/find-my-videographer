# Find My Videographer

Find, compare, and book local videographers by style, budget, location, and availability—with AI matching from a reference video.

## Project

Find My Videographer is a hackathon prototype for the **Ethical Business & Smart Operations** track. It gives customers transparent access to creator portfolios, pricing, packages, availability, and reviews while helping independent videographers manage discovery and booking requests in one place.

## Core Demo Flow

1. Upload a reference video or paste a link.
2. Receive AI-powered videographer style matches.
3. Filter by location, date, event type, and budget.
4. Compare portfolios, packages, availability, and reviews.
5. Submit a booking request.
